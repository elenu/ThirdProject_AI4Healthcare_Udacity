## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/elenu/ThirdProject_AI4Healthcare_Udacity.git
   cd ThirdProject_AI4Healthcare_Udacity
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
3. Install dependencies (indicated in Jupiter notebook).
4. Launch Jupyter: ```bash jupyter notebook ```
5. Open the main notebook and run the cells sequentially.
